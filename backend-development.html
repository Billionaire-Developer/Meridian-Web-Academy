What this program covers

The Back-End Development program focuses on what happens behind the scenes of every website and app — servers, databases, and the logic that connects them.

You'll learn to build APIs, work with databases, and understand how a back-end connects to a front-end interface, finishing with a capstone project of your own.

// learning outcomes

By the end, you'll be able to

  • 01Understand how servers, requests, and responses work
  • 02Build a simple API using Node.js and Express
  • 03Work with databases to store and retrieve data
  • 04Connect a back-end service to a front-end application

Yes. Most students who join have zero prior experience. This program is built to start from first principles, so no background is assumed going in.

“I'm not sure I can afford it.”

Payment plans are available so you're not paying the full amount upfront — see the pricing options below, or start with the free Intro to Web Development class first.
