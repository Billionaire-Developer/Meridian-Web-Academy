What this program covers

The Cyber Security program introduces the core concepts behind protecting systems, networks, and data from threats.

You'll build a working understanding of how attacks happen and how they're defended against, finishing with a hands-on security assessment project.

Intensive Track

03 MONTHS

Introduction to Cybersecurity

Networking Fundamentals

Session 1 — TCP/IP & OSI model Session 2 — DNS, ports & protocols

Linux & System Security

Learn Linux fundamentals, permissions, users, processes, services, and security logs.

Session 1 — Linux command line Session 2 — Permissions, users & logs

Threats & Attack Types

Cryptography & Security Controls

Session 1 — Encryption & hashing Session 2 — Authentication & access control
