// program overview

A focused path, not a rabbit hole.

Most people don't need a two-year computer science degree to build for the web — they need a clear, guided path that gets them from zero to a working project fast.

This program is built around live instruction, structured weekly modules, and one goal: by the end of Week 5, you'll have designed, built, and deployed a real website you can put in front of clients or employers.

Sessions run twice a week and are accessible from a smartphone or computer, so you can learn without needing to invest in new equipment first.

// faq

Frequently asked questions

"I don't have any tech background — is this really for me?"

Yes. Most students who join have zero prior experience. Every program is built to start from first principles in Week 1, so no background is assumed going in.

"I'm not sure I can afford a paid program."

Start with the free Intro to Web Development class at no cost. If you decide to continue into a paid program afterward, payment plans are available so you're not paying the full amount upfront.

"I don't have a lot of free time."

Each program runs just two live sessions a week, so it's designed to fit around a job, school, or other commitments rather than replace your schedule entirely.

"Will this actually help me get work?"

Every program ends with a real capstone project you build yourself — something you can show in a portfolio, job application, or client pitch. We don't guarantee job placement, but we do guarantee you leave with tangible proof of what you can do.

Do I need a laptop to join?

No. The curriculum is designed to be followed from a smartphone, though a computer makes writing code more comfortable if you have access to one.

Do I need prior coding experience?

No. The program starts from first principles in Week 1 and builds progressively, so no background is assumed.

What's the difference between the free class and the paid programs?

The free Intro to Web Development class is a short, no-cost taste of coding basics. The paid programs (Front-End, Back-End, Virtual Assistant, and Cyber Security) go deeper, run longer, and include capstone projects, feedback, and a certificate of completion.

What does tuition include?

All live sessions and recordings, the full curriculum for that program, capstone project feedback, a certificate of completion, and access to the student community.

Is there a payment plan?

Yes. Tuition for any paid program can be split into installments instead of paid in full upfront — contact us to set one up.

Can I take more than one program?

Yes. Many students start with the free class, then move into Front-End, Back-End, Virtual Assistant, or Cyber Security once they know which path fits them best.

What happens after the capstone?

You'll leave with a live, deployed website you built yourself, along with a certificate of completion and guidance on next steps, whether that's freelancing, further study, or a job search.
